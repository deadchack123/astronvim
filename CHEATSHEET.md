## Новое в nvim

### Прыжки по экрану — flash

| | |
|---|---|
| `s` + 1-3 символа + метка | прыгнуть к месту на экране |
| `s` + символы, если совпадение одно | прыжок сразу, метку не ждать |
| `<CR>` после набора | к ближайшему совпадению |
| `<Esc>` | отмена |

Работает с операторами: `d` + `s` + символы + метка — удалить до той точки. Так же `y`, `c`, `v`.

Нативный `s` (удалить символ + insert) заменён на **`cl`**.
`f`/`t`/`F`/`T` и поиск `/` не тронуты.

### Поиск и замена по проекту — grug-far

| | |
|---|---|
| `<Leader>sr` | открыть (в visual — с выделенным текстом) |
| `,r` | применить замену ко всем файлам |
| `,q` | выгрузить в quickfix |
| `,f` | пересобрать поиск |
| `<CR>` | перейти к файлу под курсором |
| `,c` | закрыть |
| `g?` | справка |

Поля: Search, Replace, Files Filter (`*.ts`), Flags.
Полезные флаги: `--fixed-strings` (без регулярок), `--ignore-case`, `-w` (целые слова).
Список совпадений обновляется на лету, файлы не трогаются до `,r`.

### Диагностики проекта — trouble

| | |
|---|---|
| `<Leader>xx` | все ошибки проекта |
| `<Leader>xX` | только текущий файл |
| `<Leader>xt` | все TODO/FIXME |
| `<Leader>xr` | где используется символ под курсором |

Внутри панели: `j`/`k` — превью следует за курсором, `<CR>` — перейти и закрыть, `o` — перейти и оставить, `<Tab>` — свернуть группу, `q` — закрыть, `?` — справка.

### Схемы JSON/YAML — SchemaStore

Ничего нажимать не надо. В `package.json`, `tsconfig.json`, `.eslintrc`, `.prettierrc`, `docker-compose.yml`, GitHub Actions теперь:

- автодополнение полей с описаниями (меню всплывает само)
- ошибка при неверном типе значения

Клавиши автодополнения: `<C-Space>` — показать/документация, `<Tab>`/`<S-Tab>` — по списку, `<CR>` — принять, `<C-e>` — закрыть.

### Восстановленное

`<C-a>` — снова инкремент числа под курсором (`<C-x>` — декремент).
`<Leader>T*` — тесты, теперь с подписями в which-key.

## Новое в tmux

### Изменённые команды

| | |
|---|---|
| `prefix + \|` | вертикальный сплит **в текущей директории** |
| `prefix + -` | горизонтальный сплит **в текущей директории** |
| `prefix + c` | новое окно **в текущей директории** |
| `prefix + r` | перечитать конфиг, теперь с подтверждением |
| `prefix + m` | zoom панели на весь экран |

### Копирование

1. `prefix + [` — войти в copy-mode
2. `v` — начать выделение (навигация как в vim)
3. `y` — **скопировать и выйти**

Текст попадает прямо в буфер обмена macOS. `Cmd+V` вставляет куда угодно.

### Имена окон

Ставятся автоматически по имени директории. Переименовать вручную — `prefix + ,`; после этого окно перестаёт переименовываться само, остальные продолжают.

### Уведомления от Claude

Когда Claude заканчивает задачу, его окно **подсвечивается оранжевым** в статусбаре. Подсветка снимается при переключении в это окно.

Звука нет. Иконка Ghostty в доке подпрыгивает.

## Что поменялось под капотом

- `TERM` внутри tmux — `tmux-256color`, truecolor и волнистые подчёркивания работают честно, а не через `COLORTERM`
- Скроллбек 100 000 строк (в новых панелях)
- Нумерация окон перестраивается после закрытия — цифры не разъезжаются
- На сохранении TS-файла один форматтер вместо трёх
- Python: `ruff` линтит и форматирует, `black`/`isort` убраны
- Dockerfile и docker-compose получили свои LSP

## Диагностика, если что-то отвалилось

```sh
tmux show -s extended-keys                  # on
tmux show -g history-limit                  # 100000
tmux show -g monitor-bell                   # on
tmux display -p '#{client_termfeatures}'    # содержит extkeys, RGB, usstyle
```

Проверить подсветку окна: перейти в другое окно, выполнить `printf '\a'`, вернуться — окно должно гореть.

В nvim: `:Lazy` — список плагинов, `:checkhealth` — общая диагностика, `:LspInfo` — что подключено к текущему файлу.
